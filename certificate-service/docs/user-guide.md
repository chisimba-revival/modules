# Certificates: short user guide

The Certificates page has three separate sections. Save each section with its own button; saving one section does not clear or submit either of the others.

## Open Certificates

Site administrators can open **Certificates** from **Site Administration → Shared Resources**. When working inside a course, open the same page in that course’s scope to assign its certificate.

## 1. Create a certificate design

A certificate design controls the organisation details, logo and colours used on the finished A4 certificate.

1. Select **New design**, or select **Edit** beside an existing design.
2. Enter the design, company and contact details.
3. Choose an organisation logo in PNG or JPEG format if required.
4. Choose the text and border colours, or select **Reset default colours**.
5. Select **Save certificate design**. A newly selected logo is uploaded only when the design is saved.

Saved designs appear below the form. Use **Edit** to change one, **View/download sample** to inspect its finished PDF, or **Delete** to remove an unused design.

When editing, leave the logo chooser empty to retain the saved logo.

## 2. Create a signer

The signer supplies the name, title and signature displayed on the certificate.

1. Select **New signer**, or select **Edit** beside an existing signer.
2. Enter the signer’s name and title.
3. Choose a PNG or JPEG signature image if required.
4. Select **Save signer**.

When editing, leave the signature chooser empty to retain the saved signature.

## 3. Assign the certificate to a course

1. In the **Course certificate** section, choose a saved certificate design.
2. Choose a saved signer.
3. Select **Save course certificate**.

The course may issue the selected certificate only after the learner has completed all required content. If the course contains assessments, the learner must also achieve the required passing result.

## Before learners use it

Use **View/download sample** and check:

- the organisation logo;
- the learner and course-title spacing;
- the signer’s name, title and signature;
- the company name, location and website URL;
- the text, border and seal colours.

Certificate designs and signers are reusable. Create another design or signer only when a course needs different branding or authorisation.
