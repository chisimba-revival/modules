# Paused for future revival

Preserved by Derek's decision on 15 October 2026. Do not register or enable this
module under either its old name or its paused directory name. All historical
source and database data are retained. The old routes are intentionally absent.

OER and its only external user-data dependency are preserved together as
`oer__PAUSED` and `oeruserdata__PAUSED`. Shared Validate assets have been removed;
legacy loader references here document migration work, not supported runtime use.
Before revival audit account ownership/administrator permissions, anonymous
self-registration versus account editing, POST/CSRF, prepared dbTable queries,
output escaping and PHP 8 compatibility. Replace old validation and Canvas block
editing with maintained services, then run isolated installation, security and
browser tests. Renaming the directory back alone is not a safe revival.
