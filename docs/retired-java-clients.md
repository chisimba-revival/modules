# Retired Java clients

On 12 October 2026, LiveChat and RTT were removed after read-only checks confirmed neither was registered on local or any of the six production sites. Their Java/Web Start bundles and controllers are retired. Historical tables and records are retained; this change includes no data-deletion migration.

Deploy with the coordinated framework interactive-viewer retirement: the context-home LiveChat hook is removed and RTT shortcodes no longer load the service. Discussion and Sitemap preserve original FreeMind export links; Active Knowledge Maps is the maintained mapping tool. Production deployment is pending.
